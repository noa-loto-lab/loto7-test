⑦ GitHubへの反映手順(手作業)

このページはGitHubに書き込みません。次の手順を、船長の手で行ってください。

  1. ダウンロードした default-data.json を確認する(ファイル名が default-data.json で、端末に保存されているか)。
  2. GitHubで noa-loto-lab/loto7-test を開く。
    https://github.com/noa-loto-lab/loto7-test
  3. 既存の default-data.json を、ダウンロードしたファイルで置き換える(同じ名前のファイルを上書きアップロードする)。
  4. 変更内容を確認して、コミットする。
  5. GitHub Pagesに公開されたら、予想ツールの設定から「内蔵データを読み込む」を実行し、最新回・開催日・本数字・ボーナス数字を確認する。
    https://noa-loto-lab.github.io/loto7-test/
