### 画面構成
- **A 操作バー(上部固定)**: 左にロト7表示 / 縮小(−) / 拡大(＋)、右に「メモを開く」(文字ラベル付き)と設定(歯車。外枠なしのアイコンだけ)

## 追加:CSV読み込み
### 使い方
1. 操作行の「CSV読み込み」をタップ → iPhoneでは「ファイル」アプリ(またはiCloud Drive・このiPhone内)からCSVを選ぶ。
2. 読み込みに成功すると、履歴表が入れ替わり、重ねて表示されるメッセージにファイル名・収録回数・最新回(開催日)が出る(約6秒で自動的に消える。「閉じる」でも閉じられる)。
3. 「CSV読み込み」の右の小さな表示は、読み込んだ最新回(例:`699回`)。起動直後・再読み込み後は `サンプル`(仮データ)。
4. CSVの内容はブラウザの中だけで処理され、サーバーへは送信されません。(v3.9改善で、読み込んだ履歴はブラウザに保存されるようになりました。下の「v3.9改善」を参照。)

### CSVの仕様
- 文字コード:CP932(Shift_JIS系)。UTF-8(BOMの有無どちらも)も自動判別して読める。
- 1行目:見出し(`開催回,開催日,第1数字〜第7数字,ボーナス数字1,ボーナス数字2`の11列、この文字どおり)。2行目以降:抽選履歴(1行11列)。
- 開催日:`2013/4/5`、`2013-04-05`、`2013.4.5`、`2013年4月5日` のいずれかの形式で、実在する日付。
- 行の並び順は問いません(開催回で並べ替えます)。最新回はCSVの最大の開催回から自動判定し、直近40回を古い順(上)→新しい順(下)で表示します。

### 検証(1つでも失敗すると読み込まず、元の履歴をそのまま維持)
見出し・列数 / 開催回が正の整数で重複なし / 開催日が実在する日付 / 本数字が1〜37の整数で7個すべて異なる / ボーナス数字が1〜37の整数で、本数字および互いに重複しない / 空欄・不正な値なし / 空ファイル・見出しのみ・5MB超。エラーは行番号と理由で表示(最大8件+残り件数)。

### 既存機能への影響

# v4.0 追加:予想メモ(テスト用)

基準コード:`loto7-v39-improved.zip`。既存機能(CSV読み込みと抽選履歴のIndexedDB保存・選択数字の保存・色設定・縮尺・スクロール・開催回/日付の2段表示)は変更していません。

## できること
- **画面下部の固定メニュー**で「出目表」「予想メモ」を切り替え。予想メモは出目表の上に重ねて表示するので、出目表のスクロール位置・縮尺・選択数字はそのまま戻ってきます。
- **予想メモに追加**(選択行の右端のボタン):選択が7個のときだけ保存。7個未満ならボタンを押すと「あと○個選んでください」と表示。同じ組み合わせを何度でも保存可。保存しても出目表の選択は変わりません。
- **予想メモ画面**:予想1、予想2…のカード(数字は1行)。マーク「★ 買う」「？ 迷い中」(同じマークをもう一度押すと「マークなし」)、「すべて / ★ 買う / ？ 迷い中」の絞り込み、「出目表で開く」、「削除」(確認あり)。
- **出目表で開く**:選択を、その予想の7数字に置き換えて出目表へ。いまの選択が違う数字のときは置き換え確認が出ます。呼び出した予想を直しても元の予想は変わらず、「予想メモに追加」で新しい予想になります。選択行に「予想4を呼び出し中 / 予想4から修正中」と表示し、新しい予想のカードには「元:予想4」(タップで元の予想へ移動)が付きます。
- **抽選回ごとの管理**:対象回は「最新の開催回+1」です(CSVが699回までなら第700回)。予想メモ画面の「対象回」で過去回の予想も見られます(追加は常に作成中の回)。CSVの正常な読み込みで対象回が自動で次の回に切り替わり、出目表の選択数字だけがリセットされます。過去回の予想メモは消えません。CSVの読み込みに失敗したときは、対象回も予想メモも変わりません。

## 保存のしくみ
- 予想メモは専用のIndexedDB `loto7-memo`(予想 `memos` / 番号カウンタ `meta`)に保存。ブラウザ内だけで、サーバーへは送信しません。
- 抽選履歴・選択数字のDB `loto7-prediction`(バージョン1)は**変更していません**(バージョンを上げていません)。
- 追加・マーク変更・削除は、保存に成功してから画面に反映します。失敗したときはエラーを表示し、画面は変えません。
- 予想番号は対象回ごとに採番し、削除しても振り直しません(予想2を消すと 予想1,予想3…)。
- 保存機能が使えない端末(プライベートブラウズなど)では、画面上だけで動作し、警告を表示します(閉じると消えます)。
- CSV未読込(サンプル表示)のときの予想は、対象回「サンプル(CSV未読込)」として別に保存されます。
